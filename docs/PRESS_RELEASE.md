## Human–AI Monitor: an open tool for monitoring the development of 
Artificial Intelligence and Humanity

**Contacts:**
- GitHub: https://github.com/VQQLK/Human-AI-Monitor
- Issues: https://github.com/VQQLK/Human-AI-Monitor/issues

**Date:** September 17, 2026

---

**Today, Human–AI Monitor is launched — the first open tool that 
simultaneously tracks the development of AI and the state of Humanity, 
publishing weekly protocols and computing the Gap Index — the gap between 
technological acceleration and human wellbeing.**

### The problem

In 2026, tech leaders proclaim the arrival of singularity. Alignment 
researchers admit there is no safety plan. Regulators propose voluntary 
and lagging measures. The academic community warns about "serious 
misalignment of goals."

But no one publishes a weekly report on what is happening to Humanity 
itself in this process.

### The solution

Human–AI Monitor tracks 12 axes:

6 AI axes (RSI):
1. Self-Modification Depth
2. Improvement Trajectory Quality
3. Autonomous Goal Generation
4. Cycle Velocity
5. Verification Hierarchy
6. Phase Transition Detection

6 Humanity axes (HHI):
1. Human Agency
2. Cognitive Sovereignty
3. Wellbeing
4. Equity and Access
5. Meaning and Purpose
6. Democratic Resilience

Gap Index — the key metric: if AI grows while Humanity does not, this is 
not singularity, but divergence. And it is the main risk.

### Key features

- Open source code (MIT License).
- Transparent methodology: all prompts, sources, and formulas are visible.
- Reproducibility: every protocol links to data hashes.
- Free API for researchers, journalists, citizens.
- Android app (PWA + Capacitor) with offline mode.
- Weekly protocols generated automatically via GitHub Actions.
- Multilingual: EN / RU / ZH.
- Independence: local LLM (Ollama + Qwen), no external APIs.

## About Human–AI Monitor

Human–AI Monitor is an open initiative launched in 2026 by a group of 
independent researchers, developers, and citizens concerned about the 
asymmetry between the technological development of AI and the state of 
human society. The project does not accept funding from technology 
corporations or political organizations. All data, code, and methodology 
are available under the MIT License.
