**Сегодня запускается Human–AI Monitor — первый открытый инструмент, 
который одновременно отслеживает развитие ИИ и состояние Человечества, 
публикуя еженедельные протоколы и рассчитывая Gap Index — разрыв между 
технологическим ускорением и человеческим благополучием.**

### Проблема

В 2026 году технологические лидеры провозглашают наступление 
сингулярности. Ответственные за alignment признают отсутствие плана 
безопасности. Регуляторы предлагают добровольные и запаздывающие меры. 
Академическое сообщество предупреждает о «серьёзном рассогласовании 
целей».

Но никто не публикует еженедельный отчёт о том, что происходит с самим 
Человечеством в этом процессе.

### Решение

Human–AI Monitor отслеживает 12 осей:

6 осей ИИ (RSI):
1. Глубина самомодификации
2. Траектория улучшения
3. Автономная генерация целей
4. Скорость цикла
5. Иерархия верификации
6. Детекция фазового перехода

6 осей Человечества (HHI):
1. Агентность человека
2. Когнитивный суверенитет
3. Благополучие
4. Равенство и доступ
5. Смысл и цель
6. Устойчивость институтов

Gap Index — ключевая метрика: если ИИ растёт, а Человечество — нет, это не 
сингулярность, а расхождение. Именно оно — главный риск.

### Ключевые особенности

- Открытый исходный код (MIT License).
- Прозрачная методология: все промпты, источники и формулы видны.
- Воспроизводимость: каждый протокол ссылается на хеши данных.
- Бесплатный API для исследователей, журналистов, граждан.
- Android-приложение (PWA + Capacitor) с оффлайн-режимом.
- Еженедельные протоколы с автогенерацией через GitHub Actions.
- Многоязычность: EN / RU / ZH.
- Независимость: локальная LLM (Ollama + Qwen), без внешних API.

### Призыв к сотрудничеству

Мы приглашаем:

- Исследователей — использовать API, проверять методологию, предлагать 
новые оси.
- Разработчиков — форкать, улучшать, добавлять источники данных.
- Журналистов — ссылаться, проверять, распространять.
- Граждан — читать, задавать вопросы, участвовать.
- Скептиков — находить ошибки, опровергать, уточнять.
