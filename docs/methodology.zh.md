## 1. 为什么需要方法论

"奇点是否正在到来？"这个问题自1993年以来一直在讨论——自弗诺·文奇(Vernor Vinge)的文章以来。三十多年来，出现了数十种定义，但没有一个可测量的标准。

技术领导者宣称奇点已经到来。对齐(alignment)研究人员承认没有计划。监管机构提出自愿措施。科学家警告目标错位。

**但没有人发布带有数字的周报。**

Human–AI Monitor 提出了一种操作化的结构：**13个轴 (12+1)，带有明确的阈值**，每个阈值都是可证伪的。我们不预测未来——我们记录现在。

## 2. 十三个轴 (12+1)

监测系统建立在对称结构之上：**6个轴描述人工智能(AI)，6个轴描述人类(Humanity)**。这种对称性不是偶然的——它反映了一个假设：AI的发展和人类的发展是相互关联的，它们之间的差距是关键变量。

### 2.1. AI轴 (RSI — 递归自我改进)

| 符号 | 名称 | 测量内容 | 重新评估阈值 |
|:---|:---|:---|:---|
| **SMD** | Self-Modification Depth | 自我修改深度 (L0–L4) | 在≥2个独立系统中可重现的L4 |
| **ITQ** | Improvement Trajectory Quality | 斜率、加速度、平台退出 | 持续迁移 + 加速度 > 0 |
| **AGG** | Autonomous Goal Generation | 新颖性、可行性、目标质量 | 无外部任务的专家级意义 |
| **Cycle Velocity** | Cycle Velocity | 代际改进之间的时间 | <2个月 + 完成率 >50% |
| **Verification** | Verification Hierarchy | 谁验证：正式 / 执行 / LLM / 自我评估 | 无监督下误报率 <5% |
| **Hexad** | Phase Transition Detection | SGD与高斯替代之间的MMD | 在≥2个系统中持续超越 |

### 2.2. 人类轴 (HHI — 人类视野指数)

| 符号 | 名称 | 测量内容 | 警戒阈值 |
|:---|:---|:---|:---|
| **H1 Agency** | Human Agency | 不委托给AI的决策能力 | 关键领域持续下降 |
| **H2 Sovereignty** | Cognitive Sovereignty | 批判性思维、判断独立性 | 无法区分AI内容的比例增长 |
| **H3 Wellbeing** | Wellbeing & Mental Health | 心理健康、孤独、焦虑 | 青年中焦虑和孤独感上升 |
| **H4 Equity** | Equity & Access | AI利益分配、数字不平等 | 计算资源鸿沟增长 |
| **H5 Meaning** | Meaning & Purpose | 生活意义、工作满意度 | 在工作中找到意义的比例下降 |
| **H6 Democracy** | Democratic Resilience | 对机构的信任、抵御虚假信息 | 信任持续下降 |

## 3. 差距指数 (Gap Index)

### 3.1. 公式

**差距指数是项目的关键指标。** 它衡量AI发展与人类状态之间的差距：

$$
G = \sum_{i=1}^{6} w_i^{AI} \cdot a_i - \sum_{j=1}^{6} w_j^{H} \cdot h_j
$$

其中：
- $a_i \in [0, 1]$ — 第i个AI轴的水平
- $h_j \in [0, 1]$ — 第j个人类轴的水平
- $w_i^{AI}, w_j^H$ — 权重（归一化，$\sum w = 1$）

### 3.2. 权重（当前版本）

**AI轴：**
- SMD: 0.20
- ITQ: 0.15
- AGG: 0.15
- Cycle Velocity: 0.20
- Verification: 0.20
- Hexad: 0.10

**人类轴：**
- H1 Agency: 0.20
- H2 Sovereignty: 0.15
- H3 Wellbeing: 0.20
- H4 Equity: 0.15
- H5 Meaning: 0.15
- H6 Democracy: 0.15

### 3.3. 解释

| G值 | 解释 |
|:---:|:---|
| **$G > 0.2$** | 关键不对称：AI领先于人类 |
| **$0.1 < G \leq 0.2$** | 中度不对称 |
| $\|G\| \leq 0.1$ | 对称发展（常态） |
| **$-0.2 \leq G < -0.1$** | 有利于人类的中度不对称 |
| **$G < -0.2$** | 异常：人类领先于AI |

### 3.4. 动态 $G(t)$

差距指数不是标量，而是轨迹。我们每周记录并分析：

- **趋势：** 上升 / 下降 / 稳定
- **加速度：** 二阶导数
- **吸引子：** 系统趋向何处

**关键假设：** 在AI轴没有阈值变化的情况下，$G$ 的持续增长不是奇点，而是分歧。这是主要风险。

## 4. 监测程序

### 4.1. 每周周期

**数据收集（周一，06:00 UTC）：**
- RSS订阅源（arXiv、实验室、分析）
- 新闻来源（AP、Reuters、BBC）
- 全球指数（季度）

**分类（LLM）：**
- 每个项目沿13个轴 (12+1) 分类
- 模型：Cloudflare Workers AI (`@cf/qwen/qwen3-30b-a3b-fp8`)
- 提示词：开放，位于 `prompts/`

**去重（D1）：**
- 按哈希去除重复
- 存储所有带日期的项目

**协议生成（Markdown）：**
- 13个轴 (12+1) + 差距指数的章节
- 阈值变化标记（是/否/不确定）
- 指向原始来源的链接

**发布：**
- `data/protocols/YYYY-MM-DD.md` — 进入Git
- API端点 — 供研究人员使用

### 4.2. 信号纳入标准

如果满足以下条件，信号将被纳入协议：
- **相关性 ≥ 0.4**（LLM评分）
- **来源可验证**（原始来源、同行评审出版物、官方声明）
- **日期** — 在一周内

### 4.3. 阈值变化评估

| 值 | 含义 |
|:---|:---|
| **yes** | 阈值明确达到（可重现，已确认） |
| **no** | 阈值未达到 |
| **uncertain** | 数据不足 / 无实证的主张 |

## 5. 原则

### 5.1. 透明度
所有提示词、来源和公式都是开放的。任何人都可以重现协议。

### 5.2. 可重复性
每个协议链接到：
- 源数据的哈希
- 分类器版本
- 生成日期

### 5.3. 可证伪性
每个阈值都是可验证的主张。如果达到——预测将被修订。

### 5.4. 独立性
该项目不隶属于任何实验室、国家或政治组织。开放权重模型——无外部API。

### 5.5. 永久免费
MIT License。使用、分叉、改进——免费。

---

## 6. 局限性

- **依赖公开来源。** 公司内部数据（推理链、指标）——不可用。

- **解释不确定性。** 区分真正的自主与复杂的模仿——是一个有争议的话题。

- **样本限制。** 分析涵盖已验证案例；其他可能存在于公开领域之外。

- **权重主观性。** 权重 $w_i$ 是专家估计。它们可以通过PR修订。

- **LLM分类。** 模型可能会出错。所有结果都开放验证。
