## 1. 为什么需要方法论

"奇点是否正在到来？"这个问题自1993年以来一直在讨论——自弗诺·文奇(Vernor Vinge)的文章以来。三十多年来，出现了数十种定义，但没有一个可测量的标准。

技术领导者宣称奇点已经到来。对齐(alignment)研究人员承认没有计划。监管机构提出自愿措施。科学家警告目标错位。

**但没有人发布带有数字的周报。**

Human–AI Monitor 提出了一种**操作化的结构**：**13个轴 (12+1)，带有明确的阈值**，每个阈值都是**可证伪**的。我们不预测未来——我们**记录现在**。

## 2. 十三个轴 (12+1)

监测系统具有 **两个平行的轴组**：6个轴描述**人工智能** (AI)，6个轴描述**人类** (Humanity)。两个轴组都按周监测。

### 2.1. AI轴 (RSI — 递归自我改进)

| 符号 | 名称 | 测量内容 | 重新评估阈值 |
|:---|:---|:---|:---|
| **SMD** | Self-Modification Depth | 自我修改深度 (L0–L4) | 在≥2个独立系统中可重现的L4 |
| **ITQ** | Improvement Trajectory Quality | 斜率、加速度、平台退出 | 持续迁移 + 加速度 > 0 |
| **AGG** | Autonomous Goal Generation | 新颖性、可行性、目标质量 | 无外部任务的专家级意义 |
| **Cycle Velocity** | Cycle Velocity | 代际改进之间的时间 | <2个月 + 完成率 >50% |
| **Verification** | Verification Hierarchy | 谁验证：正式 / 执行 / LLM / 自我评估 | 无监督下误报率 <5% |
| **Hexad** | Phase Transition Detection | SGD与高斯替代之间的MMD | 在≥2个系统中持续超越 |

### 2.2. 人类轴 (HHI — 人类视野指数)

| 符号 | 名称 | 测量内容 | 警戒阈值 |
|:---|:---|:---|:---|
| **H1 Agency** | Human Agency | 不委托给AI的决策能力 | 关键领域持续下降 |
| **H2 Sovereignty** | Cognitive Sovereignty | 批判性思维、判断独立性 | 无法区分AI内容的比例增长 |
| **H3 Wellbeing** | Wellbeing & Mental Health | 心理健康、孤独、焦虑 | 青年中焦虑和孤独感上升 |
| **H4 Equity** | Equity & Access | AI利益分配、数字不平等 | 计算资源鸿沟增长 |
| **H5 Meaning** | Meaning & Purpose | 生活意义、工作满意度 | 在工作中找到意义的比例下降 |
| **H6 Democracy** | Democratic Resilience | 对机构的信任、抵御虚假信息 | 信任持续下降 |

## 3. 差距指数（贝叶斯表述）

### 3.1. 公式

$$
G = \frac{1}{6}\sum_{j=1}^{6} h_j - \frac{1}{6}\sum_{i=1}^{6} a_i
$$

其中：
- $a_i \in [0, 1]$ — 第 i 个 AI 轴的水平；
- $h_j \in [0, 1]$ — 第 j 个人类轴的水平。

符号约定：**$G > 0$ — 人类加速更快；$G < 0$ — 人工智能加速更快。**

每个轴的水平是一个 **随机变量**，具有后验 Beta 分布（§3.2）。支持两种聚合模式：

- **基线（等权重）：** $\text{AI\_score} = \frac{1}{6}\sum_{i=1}^{6} \ell(a_i)$ —— 简单算术平均，在组内轴排列变化下保持不变。
- **生产（专家权重）：** $\text{AI\_score} = \sum_{i=1}^{6} w_i^{AI} \cdot \ell(a_i)$，其中 $\sum_i w_i^{AI} = 1$。权重表见 §3.2，理论依据见 §6。

聚合模式会记录在文档中；两种模式的结果都是可复现的。

### 3.2. 聚合与不确定性

轴水平以后验分布的形式估计。对于每个轴 $a$，水平建模为：

$$
\ell(a) \mid S_a \sim \mathrm{Beta}\left(\alpha_0 + \sum_{s \in S_a} v_s^{+},\ \beta_0 + \sum_{s \in S_a} v_s^{-}\right)
$$

采用非信息性 **Jeffreys 先验**（$\alpha_0 = \beta_0 = 1/2$）。每个信号贡献一个声音 $v_s = r_s \cdot \pi(\sigma_s, d_s)$，分为正负两部分。

在基线情况下（等权重），聚合是每组内部的 **简单算术平均**：

$$
\text{AI\_score} = \frac{1}{6}\sum_{i=1}^{6} \ell(a_i), \qquad
\text{Human\_score} = \frac{1}{6}\sum_{j=1}^{6} \ell(h_j)
$$

地缘政治轴 $g$ 被测量并发布于 `index_history` 中，但 **不包含**在 $\text{AI\_score}$ 或 $\text{Human\_score}$ 中。

**Gap 分布** $G = \text{Human\_score} - \text{AI\_score}$ 通过蒙特卡洛方法构造（$M = 10{,}000$ 次采样），给出均值与 95% 可信区间。完整数学处理见 [`docs/bayesian_framework.zh.md`](bayesian_framework.zh.md)。


**贝叶斯实现。** 在生产代码（`src/services/bayesian-gap.ts`）中，
每个轴的水平 $a_i$ 和 $h_j$ 被建模为具有Jeffreys先验 $(\alpha_0, \beta_0) = (0.5, 0.5)$ 的
**Beta后验分布** $\text{Beta}(\alpha, \beta)$。
在生产实现中，应用轴权重并通过**蒙特卡洛采样**（M = 10,000次抽样）计算：

$$
AI\_score^{(k)} = \sum_{i=1}^{6} w_i^{AI} \cdot s_i^{(k)}, \quad
G^{(k)} = Human\_score^{(k)} - AI\_score^{(k)}, \quad k = 1, \dots, M
$$

其中 $s_i^{(k)} \sim \text{Beta}(\alpha_i, \beta_i)$。最终的差距指数是
$G^{(k)}$ 的后验均值，带有95%可信区间。这提供了统计上严格的不确定性量化。

**专家权重（生产）。** 轴权重为专家估计，非源自标注数据：

| AI 轴 | 权重 | 依据 |
|-------|------|------|
| SMD | 0.20 | 自我修改深度——RSI 核心信号 |
| ITQ | 0.15 | 改进轨迹质量 |
| AGG | 0.15 | 自主目标生成 |
| Cycle Velocity | 0.20 | 改进周期速率 |
| Verification | 0.20 | 验证层级 |
| Hexad | 0.10 | 相变检测 |

| 人类轴 | 权重 | 依据 |
|--------|------|------|
| H1 Agency | 0.20 | 人类主体性 |
| H2 Sovereignty | 0.15 | 认知主权 |
| H3 Wellbeing | 0.20 | 福祉与心理健康 |
| H4 Equity | 0.15 | 公平与可及 |
| H5 Meaning | 0.15 | 意义与目标 |
| H6 Democracy | 0.15 | 民主韧性 |

$\sum_i w_i^{AI} = \sum_j w_j^{H} = 1.0$。权重开放校准；局限性见 §6。

### 3.3. 解释

差距由**两个独立的标签**报告，各自回答一个不同的问题。

| 问题 | 字段 | 依据 |
|------|------|------|
| 点估计指向哪个方向？ | `interpretation` | 后验均值 $G$ 的符号 |
| 该方向在统计上是否已确定？ | `statistically_significant` | $G$ 的 CI95 是否排除零 |

**方向（由均值决定）。**

| $G$ | 标签 |
|-----|-------|
| $G < -\varepsilon$ | 人工智能领先 |
| $|G| \le \varepsilon$ | 均衡 |
| $G > \varepsilon$ | 人类领先 |

其中 $\varepsilon = 0.05$（参见 `bayesian-gap.ts` 中的 `INTERPRET_EPS`）。
该阈值标记**可忽略的**均值幅度；若无此阈值，蒙特卡洛样本中精确的零无法
达到。

**证据（由 CI95 决定）。**

| $G$ 的 CI95 | 标签 |
|-------------|-------|
| 严格排除零 | 显著 |
| 包含零 | 不确定 |

两个标签**互相独立**：方向"人工智能领先"可以与"不确定"证据并存——当均值
为负而 CI95 较宽时。它们在 README 中作为两个独立的行报告，绝不合并为一个
断言。

**实例详解 — 2026-10-05。**

| 字段 | 值 | 解读 |
|------|-----|------|
| `gap` | −0.31 | 点估计 |
| `gap_ci95` | [−0.61, +0.01] | 95% 可信区间 |
| `interpretation` | `AI is ahead` | 方向：$G < -\varepsilon$ |
| `statistically_significant` | `0` | CI95 包含零 —— 证据不确定 |

方向行读作："点估计指向人工智能领先。"证据行读作："该方向在统计上尚未
确定。"两者都是关于样本的事实。两者都不是关于世界的断言。

**关于来源相关性的说明。** 真实 CI95 可能比名义值宽约 1.2–1.4 倍，
因为来自同一来源的样本并非独立证据（见 `HANDOFF.md §14.2.1`）。
较宽的区间更可能落入"不确定"证据行。


### 3.4. 动态 $G(t)$

差距指数不是标量，而是轨迹。我们每周记录并分析：

- **趋势：** 上升 / 下降 / 稳定
- **加速度：** 二阶导数
- **吸引子：** 系统趋向何处

**关键假设：** 在AI轴没有阈值变化的情况下，$G$ 的持续负向趋势（AI水平上升快于人类水平）**不是奇点，而是分歧**。这是主要风险。

每个周值都带有 95% 可信区间，使趋势即使在每周样本量很小的情况下也具有统计可解释性。

## 4. 监测程序

### 4.1. 每周周期

**数据收集（每日 5 批：13:00、13:15、13:30、13:45、23:00 UTC）：**
- RSS订阅源（arXiv、实验室、分析）
- 新闻来源（AP、Reuters、BBC）
- 全球指数（季度）

**分类（LLM）：**
- 每个项目沿13个轴 (12+1) 分类
- 模型：Cloudflare Workers AI (`@cf/qwen/qwen3-30b-a3b-fp8`)
- 提示词：开放，位于 `prompts/`

**去重（D1）：**
- 按哈希去除重复
- 存储所有带日期的项目

**协议生成（Markdown）：**
- 13个轴 (12+1) + 差距指数的章节
- 阈值变化标记（是/否/不确定）
- 指向原始来源的链接

**发布：**
- `data/protocols/YYYY-MM-DD.md` — 进入Git
- API端点 — 供研究人员使用

### 4.2. 信号纳入标准

如果满足以下条件，信号将被纳入协议：
- **相关性 ≥ 0.4**（LLM评分）
- **来源可验证**（原始来源、同行评审出版物、官方声明）
- **日期** — 在一周内

### 4.3. 阈值变化评估

| 值 | 含义 |
|:---|:---|
| **yes** | 阈值明确达到（可重现，已确认） |
| **no** | 阈值未达到 |
| **uncertain** | 数据不足 / 无实证的主张 |

## 5. 原则

### 5.1. 透明度

所有提示词、来源和公式都是**开放的**。任何人都可以重现协议。

### 5.2. 可重复性

每个协议链接到：
- **源数据的哈希**
- **分类器版本**
- **生成日期**

### 5.3. 可证伪性

每个阈值都是**可验证的主张**。如果达到——预测将被修订。

### 5.4. 独立性

该项目**不隶属于**任何实验室、国家或政治组织。开放权重模型——无外部API。

### 5.5. 永久免费

MIT License。使用、分叉、改进——**免费**。

## 6. 局限性

1. **依赖公开来源。** 公司内部数据（推理链、指标）——不可用。

2. **解释不确定性。** 区分真正的自主与复杂的模仿——是一个有争议的话题。

3. **样本限制。** 分析涵盖已验证案例；其他可能存在于公开领域之外。

4. **信号独立性。** 在单个轴内部假定各项独立，但单一来源可能产生相关的项（关于同一事件的一系列新闻）。这可能在小周样本下高估置信度。

5. **LLM分类。** 模型可能会出错。所有结果都开放验证。

6. **专家权重。** §3.2 中的轴权重为专家估计，非源自标注数据或理论第一原理。可以采用不同的权重方案。改变权重会影响 $\text{AI\_score}$ 和 $\text{Human\_score}$ 的幅度，但不影响其定性解释（§3.3）——只要 $G$ 的符号不变，定性解释就保持稳定。

7. **构念效度。** AI轴反映AI基准测试的新闻（提取）；人类轴反映关于人类发展的新闻话语（解释）。两者由同一流水线分类，但描述不同类型的证据。不假设尺度的直接可比性。
