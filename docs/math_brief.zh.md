## 1. 一段话概述

我们正在构建一个**开放的监测系统**，同时追踪人工智能的发展（6 个轴）和人类的状态（6 个轴），以及一个地缘政治元层，并计算 **Gap Index**——它们之间差距的定量度量——且发布每周协议。这不是新闻，也不是预测。它是**将一个问题操作化的尝试**，这个问题至今仍停留在修辞层面：奇点是否正在到来？在此过程中，人类正在经历什么？

截至 2026 年 9 月 25 日，系统已完成其**首个完全自主的每日循环**——4 个批次从 17 个源采集了 33 个条目，分类器处理了它们，并在无人干预的情况下为当周生成了中间协议。

### 2.3. 贝叶斯轴水平

每个轴水平是 [0, 1] 上的潜在随机变量，具有后验 Beta 分布。对于轴 a 及其信号集 S_a = {s₁, …, s_n}：

    ℓ(a) | S_a ~ Beta( α₀ + Σ_{s ∈ S_a} v_s⁺ ,  β₀ + Σ_{s ∈ S_a} v_s⁻ )

其中：
- α₀ = β₀ = 1/2 — 非信息性 **Jeffreys 先验**，
- v_s = r_s · π(σ_s, d_s) — 信号声音，
- v_s⁺ = max(0, v_s),  v_s⁻ = max(0, −v_s)。

**声音表** π(σ, d) ∈ [−1, 1]：

| π | up | stable | down | uncertain |
|---|---|---|---|---|
| **yes** | +1.0 | +0.5 | −1.0 | +0.5 |
| **no** | +0.3 | 0.0 | −0.3 | 0.0 |
| **uncertain** | 0.0 | 0.0 | 0.0 | 0.0 |

点估计：  ℓ̂(a) = (α₀ + Σv_s⁺) / (α₀ + β₀ + Σv_s⁺ + Σv_s⁻)。

**回退。** 当 |S_a| = 0 时，后验 = 先验 = Beta(0.5, 0.5)，均值 0.5，宽可信区间（此前为假零）。

完整贝叶斯处理见 [`docs/bayesian_framework.zh.md`](bayesian_framework.zh.md) §3.2。

### 2.4. 聚合

AI-score 和 Human-score 是各自轴集上的简单算术平均：

    AI_score    = (1/|A|) · Σ_{a∈A} ℓ(a)  = (1/6) · Σ_{a∈A} ℓ(a)
    Human_score = (1/|H|) · Σ_{a∈H} ℓ(a)  = (1/6) · Σ_{a∈H} ℓ(a)

**归一化性质：** 两个指标都位于 [0, 1]，作为 [0,1] 值的平均。

**Gap 分布。** Gap 通过蒙特卡洛方法构造（M = 10,000 次采样）：

    ℓ^(k)(aᵢ) ~ Beta(αᵢ, βᵢ),  ℓ^(k)(hⱼ) ~ Beta(αⱼ, βⱼ)   其中 k = 1..M
    Gap^(k) = AI^(k) − Human^(k)

点估计：Ĝap = mean({Gap^(k)})。  95% 可信区间：[q₀.₀₂₅, q₀.₉₇₅]。

### 2.5. Gap Index

    Gap = AI_score − Human_score

**值域：** Gap ∈ [−1, 1]（两个 [0,1] 值之差）。

**解读**（带阈值 ±0.1 和 ±0.3 的分段常数函数）：

    Gap < −0.3          → 人类显著领先
    −0.3 ≤ Gap < −0.1   → 人类领先
    −0.1 ≤ Gap ≤ 0.1    → 对称发展
    0.1 < Gap ≤ 0.3     → AI 领先
    Gap > 0.3           → AI 显著领先

**中性区** [−0.1, 0.1] 宽度为 0.2，对应小样本的统计噪声（类似于死区）。

当 Gap 的 95% 可信区间完全落在某一行之内时，解读是**稳定的**；当区间跨越阈值时，解读是**不稳定的**。

### 2.6. 分类器（LLM 接口）

分类器是一个模型 f: T* → Y*，应用于条目批次。对于单个条目，T 是文本空间（标题 + 摘要，≤800 字符），输出空间为：

    Y = {(A, r, σ, d, ρ)}

其中：
- A ⊆ (AI_axes ∪ Human_axes), 1 ≤ |A| ≤ 3（稀疏），
- r ∈ [0, 1] — 相关性分数，
- σ ∈ {yes, no, uncertain} — 位移标志，
- d ∈ {up, down, stable, uncertain} — 方向，
- ρ ∈ T — 推理（1–2 句）。

**关键规则：** σ = yes 仅在阈值位移被经验证实时允许（`src/config/prompts.ts` 中的规则 3）。

### 2.7. 统计性质

- **分类前哈希检查：** URL/标题的 SHA-256 → 数据库查询 → 仅对新条目分类。经验节省：避免约 90% 的 LLM 调用。
- **批处理：** 每天 5 批 × 约 8 个源 × 每源约 2-3 个条目 ≈ 每天 80-120 次分类。
- **Gap 标准误差。** 每个信号贡献一个声音 v_s = r_s · π(σ_s, d_s) ∈ [−1, 1]，方差为 σ_v²。在均匀性假设下（各轴大小相等 n_i = n/6，信号方差相等）：
    SE(Gap) = σ_v · √(2/n)，   CI₉₅ 宽度 ≈ 3.92 · σ_v · √(2/n)  （n ≥ 30）。
  推导：Var(AI_score) = (1/36) Σ_i Var(ℓ(a_i)) = (1/36) · 6 · σ_v²/(n/6) = σ_v²/n。Human_score 类似。独立条件下 Var(Gap) = 2 σ_v²/n，因此 SE(Gap) = σ_v · √(2/n)。
  在保守界 σ_v ≤ 0.5（对于 [0, 1] 值信号）下，SE(Gap) ≤ √(1/(2n)) ≈ 0.707 / √n。后果：
    - n = 10:  SE(Gap) ≤ 0.22  （超过中性区半宽 0.1 —— 解读不可靠）
    - n = 50:  SE(Gap) ≤ 0.10  （临界）
    - n = 170: SE(Gap) ≤ 0.054 （可接受；与当前周一致）

## 3. 为什么这引起数学家的兴趣

### 3.1. 形式化不可形式化之物

奇点是一个迄今**以文学方式**定义的概念（Vinge、Good、Altman）。我们提出一个**可测量的结构**：6 个 AI 轴 + 6 个人类轴 + 1 个元轴（地缘政治），具有明确的阈值，每个都**可证伪**。

这是将**推测转化为假设**、将假设转化为**可观测量**的尝试。

### 3.2. AI ↔ 人类对称性

13 个轴构成一个**对称结构**：6 个描述**人工**（AI）、6 个描述**人类**（Humanity），加上 **1 个元层**（`geopolitics`）。元层被单独测量并发布，**不**进入 AI_score 或 Human_score。对称性假设仍然成立：**AI 发展与人类发展相关**，二者之间的差距是关键变量。

### 3.3. 开放数学问题

**问题 1. 真正 RSI 的判据。**

何时系统的自我修改是**持续改进**，何时是**饱和**？与可计算性理论（Kleene 递归定理、停机问题）和信息论（Kolmogorov 复杂度）相关。

**形式化：** 设 S 为自改进系统，S_t 为 t 时刻的状态。RSI 是过程 S_{t+1} = f(S_t)，其中 f 是系统本身（自反性）。可持续性意味着步长具有正下界的严格单调改进：

    ∃ ε > 0 : ∀t, Capability(S_{t+1}) − Capability(S_t) ≥ ε。

这要求 Capability 无界。如果 Capability 有界（例如在 [0, 1] 上），严格单调改进仍然可能，但步长必须趋于零，"持续增长"则变得定义不良。问题：在 f 上什么条件下无界情形成立？

**问题 2. 相变检测。**

MMD 检测器（Hexad）是启发式的。需要严格理论：**如何区分自改进系统中的相变与噪声**？

**形式化：** 设 X_t 为 SGD 迭代的轨迹。我们计算 MMD(X_t, N(0, I))——到高斯代理的距离。问题：是否存在阈值 τ，使得 MMD > τ 在统计上显著地指示 X_t 偏离高斯代理？

**问题 3. 无需预言机的验证。**

验证层级（形式验证器 → 执行 → LLM 评判 → 自我评估）是一个**偏序**。何时系统可以**无人闭环**？这是关于**自指的 计算复杂度**的问题。

**形式化：** 设 V = {v₁, ..., v_n} 为验证器层级，其中 v_i < v_j 表示"v_i 比 v_j 更不可靠"。系统可以无人闭环，如果存在 v_i 使得 false_positive_rate(v_i) < 5% 且 v_i 可自主应用。问题：这样的验证器的最小柯尔莫哥洛夫复杂度 K(v_i) 是多少？

**问题 4. 作为动力系统的 Gap Index。**

G(t) 不是标量而是轨迹。能否找到**不变量**？**吸引子**是否存在？当 G → ±1 时会发生什么？

**形式化：** 设 G(t) = F(A(t), H(t))，其中 A(t) 是 AI 水平的向量，H(t) 是人类水平的向量。问题：G(t) 的轨迹上是否存在守恒量？在 [−1, 1] 内是否存在吸引子？

## 4. 项目的独特之处

### 4.1. 开放性

- **代码：** MIT 许可证，完全托管于 GitHub。
- **数据：** 所有源、提示、迁移——开放。
- **API：** 免费公开访问协议和 Gap Index。
- **可复现性：** 每个协议都链接到源数据的哈希。

### 4.2. 独立性

- **不隶属于**任何 AI 实验室、国家或政治组织。
- **开放权重模型**（Cloudflare Workers AI：Qwen 3）——无外部 API，无泄漏。
- **Cloudflare Workers** ——去中心化基础设施，无单点故障。

### 4.3. 双向性

这**不是 AI 的监测器**。这是 **AI + 人类 的监测器**。我们不仅测量 AI 做了什么，还测量**正在发生什么于我们身上**。

## 7. 协议同步时间表

### 7.1. 生成 vs 可见性

协议生成到 **D1 数据库**，但**延迟**出现在 **git 仓库**（`data/protocols/`）。这不是 bug——同步由单独的 GitHub Actions workflow 按计划处理。

### 7.2. 延迟表

| 协议类型 | 生成 (D1) | 可见 (git) | 延迟 |
|---------------|----------------|---------------|-------|
| **中间**（草案） | 周五 13:45 UTC | **周六 08:00 UTC** | ~18 小时 |
| **最终** | 周一 13:45 UTC | **周一 14:00 UTC** | ~15 分钟 |

### 7.3. 为什么有延迟？

- **中间：** 周五 13:45 生成，周六 08:00 同步——允许发布前周末审核。
- **最终：** 周一 13:45 生成，周一 14:00 同步——近乎立即发布。

### 7.4. 同步 Workflow

在 `.github/workflows/sync-protocols.yml` 中定义：

    on:
      schedule:
        - cron: "0 14 * * 1"   # 周一 14:00 UTC — 同步最终
        - cron: "0 8 * * 6"    # 周六 08:00 UTC — 同步中间

Workflow：
1. 从 D1 API 获取最近 2 个协议（`/export-weekly?weeks=2`）。
2. 写入 collector 仓库的 `data/protocols/`。
3. 将所有协议归档到 `human-ai-monitor-archive` 仓库。
4. 触发翻译 workflow（EN→RU/ZH）。

### 7.5. 手动同步

    gh workflow run sync-protocols.yml

完整文档：`docs/architecture.md` §6 "Protocol Synchronization"。

### v1.0.1 关键修复（2026 年 9 月 25 日）

在初始 v1.0.0 发布中发现并修复了两个关键 bug：

**1. gap-computation.ts 中的俄语键（commit `13fa1c1`）**

乘数字典 `SHIFT_MULT` 和 `DIR_MULT` 使用俄语键（`'да'`/`'нет'`/`'рост'`/`'падение'`）声明，而分类器返回英文键（`yes`/`no`/`up`/`down`）。这导致查找返回 `undefined`，回退到 `?? 1`（单位乘数）。

**影响：** 模型失去对阈值位移和方向趋势的敏感性，实际上退化为按轴的平均相关性。

**修复：** 将所有乘数键翻译为英文，恢复完整的数学模型功能。

**2. 测试后 Miniflare 挂起（commit `5f5721d`）**

所有 66 个测试通过后，Miniflare 未能关闭 WebSocket、ZLIB 流和 FileHandle 资源，导致 10 秒超时挂起（总运行时间 24s 而不是 ~5s）。

**修复：** 添加了 `test/global-teardown.ts`，带 2 秒宽限期后跟 `process.exit(0)`。将 `teardownTimeout` 从 10s 减少到 3s。在测试中禁用 `remoteBindings`。

**结果：** 测试套件现在在 **8 秒**内完成，而不是 24 秒。
