**今天，Human–AI Monitor 正式启动——这是首个同时追踪人工智能发展和人类状态、每周发布协议并计算差距指数（Gap Index）——技术加速与人类福祉之间差距——的开放工具。**

### 问题

2026 年，科技领袖们宣称奇点即将到来。对齐（alignment）研究者承认没有安全计划。监管者提出自愿且滞后的措施。学术界警告"目标严重失准"。

但没有人每周发布关于人类自身在此过程中发生什么的报告。

### 解决方案

Human–AI Monitor 追踪 13 个轴（12+1）：

6 个 AI 轴（RSI）：
1. 自我修改深度
2. 改进轨迹质量
3. 自主目标生成
4. 周期速度
5. 验证层级
6. 相变检测

6 个人类轴（HHI）：
1. 人类主体性
2. 认知主权
3. 福祉
4. 公平与可及
5. 意义与目标
6. 民主韧性

差距指数——核心指标：如果 AI 在增长而人类没有，这不是奇点，而是偏离。它才是主要风险。

### 关键特性

- 开源代码（MIT 许可证）。
- 透明方法论：所有提示、来源和公式均可见。
- 可复现性：每个协议都链接到数据哈希。
- 面向研究者、记者、公民的免费 API。
- Android 应用（PWA + Capacitor），支持离线模式。
- 通过 GitHub Actions 自动生成每周协议。
- 多语言：EN / RU / ZH。
- 独立性：无服务器 LLM（Cloudflare Workers AI + Qwen），无外部 API。
