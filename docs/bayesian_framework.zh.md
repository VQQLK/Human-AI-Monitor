# Human–AI Monitor：当前方法论与贝叶斯替代方案

**文档版本：** v2.0-draft  
**日期：** 2026年9月28日  
**目的：** 系统阐述当前方法论（v1.0.1）并论证用于轴聚合和差距指数计算的贝叶斯模型（v2.0）  
**状态：** 工作文档，开放审查

---

## 1. 引言

### 1.1 项目

Human–AI Monitor 是一个开放的监测系统，同时追踪人工智能的发展和人类的状态，并发布每周协议。其主要产品是 **Gap Index**——衡量 AI 水平与人类水平之间差距的定量指标。

### 1.2 测量结构

系统操作 **13 个轴**：

- **A = {a₁, …, a₆}** — 六个 AI 轴（RSI — Recursive Self-Improvement）：`SMD`（Self-Modification Depth）、`ITQ`（Improvement Trajectory Quality）、`AGG`（Autonomous Goal Generation）、`Cycle Velocity`、`Verification`、`Hexad`。
- **H = {h₁, …, h₆}** — 六个人类轴（HHI — Human Horizon Index）：`H1 Agency`、`H2 Sovereignty`、`H3 Wellbeing`、`H4 Equity`、`H5 Meaning`、`H6 Democracy`。
- **G = {g}** — 一个地缘政治元轴：被测量并发布，但**不包含**在 `AI_score` 或 `Human_score` 中。

结构公式：`13 = 6 + 6 + 1`。

### 1.3 对称性假设

项目的核心假设：**AI 的发展和人类的发展是相互关联的**，而它们之间的差距是关键的可观察变量。6↔6 对称并非偶然——它反映了这样一个假设：六个 RSI 轴和六个 HHI 轴描述的是同等重要的测量维度。

**数学推论。** 如果对称性假设被接受为公设，则每组内的聚合函数必须**在轴置换下不变**。否则，对称性在公式层面被破坏，而非在理论层面。这限制了可接受聚合器的类别。

### 1.4 差距指数

差距指数 `G(t)`：

```
G(t) = AI_score(t) − Human_score(t)
```

其中 `AI_score` 是对 AI 水平的聚合估计，`Human_score` 是对人类水平的聚合估计。

### 1.5 数据来源

每周从约 40 个 RSS 源收集。每个条目由语言模型（Qwen 3，`@cf/qwen/qwen3-30b-a3b-fp8`）分类，并获得：

- `r_s ∈ [0, 1]` — 相关性（分类器置信度），
- `σ_s ∈ {yes, no, uncertain}` — 阈值位移标志，
- `d_s ∈ {up, down, stable, uncertain}` — 趋势方向，
- `A_s ⊆ (A ∪ H ∪ G)`，`1 ≤ |A_s| ≤ 3` — 条目被归入的轴集合。

一周内，累积 `|S| ≈ 100–200` 个条目，分布在各个轴上。归入轴 `a` 的条目集合记作 `S_a`。

## 2. 当前方法论（v1.0.1）

这是代码 `src/services/gap-computation.ts` 中实现的现行版本，部分反映在 `docs/methodology.md` 中。

### 2.1 轴级别

轴级别由乘法公式计算：

```
ℓ(a) = clamp_[0,1] ( (1/|S_a|) · Σ_{s ∈ S_a} r_s · M_shift(σ_s) · M_dir(d_s) )
```

其中 `clamp_[0,1](x) = max(0, min(1, x))` 是到区间的投影。

**位移乘数** `M_shift`：

| `σ_s` | `M_shift(σ_s)` |
|---|---|
| yes | 1.5 |
| uncertain | 1.0 |
| no | 0.5 |

**方向乘数** `M_dir`：

| `d_s` | `M_dir(d_s)` |
|---|---|
| up | 1.2 |
| stable | 1.0 |
| uncertain | 1.0 |
| down | 0.8 |

对于 `|S_a| = 0`（无条目），假定 `ℓ(a) = 0`。

### 2.2 聚合

代码在每组内使用**简单算术平均**：

```
AI_score    = (1/6) · Σ_{i=1}^{6} ℓ(a_i)
Human_score = (1/6) · Σ_{j=1}^{6} ℓ(h_j)
```

地缘政治轴 `g`：计算 `ℓ(g)` 并发布在 `index_history` 中，但不包含在 `AI_score` 或 `Human_score` 中。

### 2.3 methodology.md 中的替代公式

文档 `docs/methodology.md`（第 3.1–3.2 节）包含**另一个公式**——带固定权重的加权和：

```
AI_score    = Σ_{i=1}^{6} w_i^AI · a_i,     Σ w_i^AI = 1
Human_score = Σ_{j=1}^{6} w_j^H  · h_j,     Σ w_j^H  = 1
```

**AI 轴权重：**

| 轴 | 权重 |
|---|---|
| SMD | 0.20 |
| ITQ | 0.15 |
| AGG | 0.15 |
| Cycle Velocity | 0.20 |
| Verification | 0.20 |
| Hexad | 0.10 |

**人类轴权重：**

| 轴 | 权重 |
|---|---|
| H1 Agency | 0.20 |
| H2 Sovereignty | 0.15 |
| H3 Wellbeing | 0.20 |
| H4 Equity | 0.15 |
| H5 Meaning | 0.15 |
| H6 Democracy | 0.15 |

**该公式未在代码中实现。** 代码使用简单平均。文档与代码之间的分歧尚未在方法论中记录。

### 2.4 解释阈值

| `G` 的范围 | 解释 |
|---|---|
| `G > 0.3` | AI 显著领先 |
| `0.1 < G ≤ 0.3` | AI 领先 |
| `−0.1 ≤ G ≤ 0.1` | 对称发展（正常） |
| `−0.3 ≤ G < −0.1` | 人类领先 |
| `G < −0.3` | 人类显著领先 |

（在 `methodology.md` 中记录了对称阈值 `±0.1` 和 `±0.2`；在代码中为 `±0.1` 和 `±0.3`。又一处分歧。）

### 2.5 当前方法的局限性

**局限性 1. 任意参数。**
值 `M_shift ∈ {1.5, 1.0, 0.5}` 和 `M_dir ∈ {1.2, 1.0, 0.8}` 并非源自理论，也非来自标注数据的校准。这是一组专家数字，没有记录获取它们的协议。因此，该指标不可重现：读者无法验证为什么恰好是 1.5 而非 1.3。

**局限性 2. 文档与代码不一致。**
代码使用简单平均；`methodology.md` §3.1–3.2 描述加权公式。两份文档描述不同的指标，但都宣称是当前的。

**局限性 3. 有界区间上的乘法性。**
对于 `r_s = 1`、`σ_s = yes`、`d_s = up`，得到 `1 · 1.5 · 1.2 = 1.8`。在应用 `clamp` 之前，该值超出 `[0, 1]` 达 1.8 倍。`clamp` 操作变得主导于聚合：边界处的非线性抹平了高相关性条目之间的差异。

**局限性 4. 效应强度不对称。**
位移范围：`1.5 / 0.5 = 3×`。方向范围：`1.2 / 0.8 = 1.5×`。为什么位移的影响是方向的两倍——未加说明。

**局限性 5. 无不确定性的点估计。**
该公式返回单个数字而无区间。对于 `|S_a| < 10`（如 2026 年 9 月 14–20 日那一周：协议中有 6 个条目），均值的标准误差超过中性区 `[−0.1, 0.1]` 的宽度，解释变得与噪声无法区分。该指标未反映这一点。

**局限性 6. 与对称性假设不一致。**
§1.3 中的假设要求在每组内对轴置换不变。加权和公式（§2.3）违反了这一点：权重 `0.20` 和 `0.15` 在没有依据的情况下固定了轴之间的偏好。简单平均（§2.2）是不变的，但在代码中应用时缺乏明确的理论动机。

## 3. 贝叶斯方法论（v2.0）

所提出的模型将启发式替换为概率表述。轴级别成为一个带有后验分布的潜在量；差距成为一个分布，而非标量。

### 3.1 问题陈述

对于每个轴 `a ∈ A ∪ H ∪ G`，要求：

1. 用完整的不确定性分布估计级别 `ℓ(a) ∈ [0, 1]`。
2. 将 `AI_score`、`Human_score`、`Gap` 构造为分布。
3. 在新条目到达时提供自然更新。

### 3.2 单轴贝叶斯模型

**先验分布。** 轴级别 `ℓ(a)` 是 `[0, 1]` 上的潜在量。我们使用共轭先验分布：

```
ℓ(a) ~ Beta(α₀, β₀)
```

选择 `α₀ = β₀ = 1/2` 是 **Jeffreys 先验**（Jeffreys 1946），非信息性且在重参数化下不变。先验均值 `E[ℓ] = 0.5` 是在无数据时的中性估计。

**信号投票。** 每个信号 `s ∈ S_a` 贡献一个"投票" `v_s ∈ [−1, 1]`：

```
v_s = r_s · π(σ_s, d_s)
```

其中 `π` 是确定性方向表（§3.4）。

我们将投票分为正负两部分：

```
v_s⁺ = max(0, v_s)
v_s⁻ = max(0, −v_s)
```

**后验分布。** 由于 Beta 似然与 Beta 先验的共轭性：

```
ℓ(a) | S_a ~ Beta( α₀ + Σ_{s ∈ S_a} v_s⁺ ,  β₀ + Σ_{s ∈ S_a} v_s⁻ )
```

**点估计：**

```
ℓ̂(a) = ( α₀ + Σ v_s⁺ ) / ( α₀ + β₀ + Σ v_s⁺ + Σ v_s⁻ )
```

**方差：**

```
Var[ℓ(a) | S_a] = α·β / ( (α+β)² · (α+β+1) )
```

其中 `α = α₀ + Σ v_s⁺`，`β = β₀ + Σ v_s⁻`。

**95% 可信区间** `[q₀.₀₂₅, q₀.₉₇₅]` — Beta 分布的分位数。

### 3.3 聚合与差距指数

**AI_score 与 Human_score。** 根据对称性假设（§1.3），两组是等价的，因此聚合是**简单平均**：

```
AI_score    = (1/6) · Σ_{i=1}^{6} ℓ(a_i)
Human_score = (1/6) · Σ_{j=1}^{6} ℓ(h_j)
```

这是唯一在轴置换下不变的聚合。

**重要性质：** 如果 `ℓ(aᵢ) ~ Beta(αᵢ, βᵢ)` 相互独立，则 `AI_score` **不服从 Beta 分布**——它是 Beta 分布变量之和，不存在闭式密度。这不是模型的缺陷，而是它的诚实之处：聚合确实会改变分布的形状。

**差距：**

```
Gap = AI_score − Human_score
```

**通过蒙特卡洛构造差距分布**（Robert & Casella 2004，第 3 章）：

1. 采样 `M = 10 000` 次：
   - `ℓ^(k)(aᵢ) ~ Beta(αᵢ, βᵢ)`，`i = 1..6`
   - `ℓ^(k)(hⱼ) ~ Beta(αⱼ, βⱼ)`，`j = 1..6`
2. 计算 `Gap^(k) = AI^(k) − Human^(k)`。
3. 估计：
   - `Ĝap = mean(Gap^(k))`
   - `CI₉₅ = [q₀.₀₂₅, q₀.₉₇₅]({Gap^(k)})`
   - `Var(Gap) = var({Gap^(k)})`

选择 `M = 10 000` 时，蒙特卡洛误差对均值约为 `1/√M ≈ 0.01`，对分位数约为 0.005——低于发表的重要精度（2 位数字）。

### 3.4 方向表 π

表 `π(σ, d) ∈ [−1, 1]`：

| π | up | stable | down | uncertain |
|---|---|---|---|---|
| **yes** | +1.0 | +0.5 | −1.0 | +0.5 |
| **no** | +0.3 | 0.0 | −0.3 | 0.0 |
| **uncertain** | 0.0 | 0.0 | 0.0 | 0.0 |

**值的论证：**

- `(yes, up) = +1.0` — 增长的完整证据：位移已确认且方向为正。
- `(yes, down) = −1.0` — 下降的完整证据：位移已确认且方向为负。
- `(yes, stable) = +0.5` — 有位移，方向未定；一半支持增长（保守）。
- `(no, up/down) = ±0.3` — 无位移，但有趋势；弱证据（完整的 30%）。
- `(no, stable) = 0.0` — 什么都没发生。
- `(uncertain, *) = 0.0` — 在不确定时信号不投票（"不伤害"原则）。

刻度 `{1.0, 0.5, 0.3, 0.0}` 基于专家判断，开放校准。与 v1 的乘数不同，它是：

- **可加的**（不缩放 `r_s` 而是添加投票），
- **对称的**（`π(yes, up) = −π(yes, down)`），
- **有界的**（不超出 `[−1, 1]`），
- **可解释的**，作为完整证据的分数。

### 3.5 贝叶斯模型的性质

**性质 1. 正确的不确定性量化。**
可信区间 `CI₉₅` 由后验分布构造（Rubin 1984）。对于小样本，区间自动变宽，使解释诚实。

**性质 2. 与对称性假设一致。**
当 `αᵢ = αⱼ` 且信号数量相等时，AI 轴和人类轴的级别分布在置换下对称。没有任何轴被单独挑出。

**性质 3. 自然更新。**
当周的后验成为下周的先验（顺序贝叶斯更新）。无需重新计算全部历史。

**性质 4. 对小样本的稳健性。**
当 `|S_a| = 0` 时，后验 = 先验 = `Beta(0.5, 0.5)`，均值 0.5，区间宽。这是正确行为，而非虚假的零。

**性质 5. 可证伪性。**
作为分布的差距允许对假设"差距显著不同于零"进行统计检验：`P(Gap > 0 | data) > 0.95`——单侧检验的贝叶斯类似物（Kruschke 2013）。

### 3.6 贝叶斯模型的局限性

**局限性 1. 信号的独立性。** 模型假定轴内信号独立。实际上，单一来源可能产生相关信号（关于同一事件的一系列新闻），这会高估置信度。解决方法——每个来源的随机效应（在 v2.1 中）。

**局限性 2. π 的专家性质。** 表 `π` 是专家刻度。形式校准需要标注数据，目前尚不可用。v2.0 发布对 `π` 变化的敏感度。

**局限性 3. 平稳性。** 模型未考虑长周期上的趋势：一周的后验不"记得"上一周。对于长期分析，将需要状态空间模型（Kalman 滤波器 / 分层贝叶斯）。

### 3.7 推理过程

**输入：** 一周的信号，按轴分组。

**算法：**

```
对每个轴 a ∈ A ∪ H ∪ G:
    α ← 0.5
    β ← 0.5
    对每个信号 s ∈ S_a:
        v ← r_s · π(σ_s, d_s)
        如果 v > 0: α ← α + v
        否则:      β ← β + (−v)
    posterior[a] ← Beta(α, β)

对每个采样 k = 1..10000:
    AI_k    ← (1/6) Σ_{i=1..6} Sample(posterior[a_i])
    Human_k ← (1/6) Σ_{j=1..6} Sample(posterior[h_j])
    Gap_k   ← AI_k − Human_k

Gap_mean ← mean({Gap_k})
Gap_CI95 ← [q₀.₀₂₅, q₀.₉₇₅]({Gap_k})
```

**复杂度：** `O(|S| + 12·M)`。在 Cloudflare Workers 上，`M = 10 000` 时约为 50 毫秒。

**贝叶斯版本的 API 响应 `/gap`：**

```json
{
  "week_start": "2026-09-21",
  "ai_score": 0.55,
  "ai_score_ci95": [0.51, 0.59],
  "human_score": 0.53,
  "human_score_ci95": [0.49, 0.57],
  "gap_mean": 0.02,
  "gap_ci95": [-0.05, 0.09],
  "gap_std": 0.04,
  "sample_size": 189,
  "statistically_significant": false,
  "interpretation": "Symmetric development"
}
```

发布值、不确定性和显著性标志——科学正确指标的三个组成部分。

### 3.8 贝叶斯模型中的解释阈值

阈值 `±0.1` 和 `±0.3` 保留为**实用刻度**，但有两项补充：

1. 如果 `CI₉₅` 完全位于一个区间内——解释是稳定的。
2. 如果 `CI₉₅` 跨越区间之间的边界——解释标记为不稳定。

这一补充不改变刻度，但使其应用在统计上正确。

### 3.9 与项目原则的对应

贝叶斯模型对应 `methodology.md`（第 5 节）中陈述的五项原则：

- **透明性。** 所有模型参数（`α₀`、`β₀`、表 `π`）均发布；蒙特卡洛过程可重现。
- **可重现性。** 输入数据相同时，结果在 `1/√M` 范围内确定（固定种子时精确）。
- **可证伪性。** 每个关于差距的陈述都通过 `CI₉₅` 和 `P(Gap > 0 | data)` 具有明确的统计意义。
- **独立性。** 模型依赖开放权重 LLM 和开放数据；概率工具是标准的。
- **永久免费。** 在 `M = 10 000` 时的蒙特卡洛适配 Cloudflare Workers 的免费层级。

## 4. 方法比较

| 标准 | 当前 v1.0.1 | 贝叶斯 v2.0 |
|---|---|---|
| 轴级别 | 乘法启发式 | 后验 Beta |
| 参数 | 4 个无依据数字 | 2 个非信息性先验 |
| 聚合 | 简单平均（代码）或权重（文档） | 简单平均 |
| 差距 | 标量 | 分布 |
| 不确定性 | 隐藏 | 显式（`CI₉₅`） |
| 小样本 | 虚假自信的数字 | 诚实宽区间 |
| 更新 | 完全重算 | 顺序（后验 → 先验） |
| 与 §1.3 的一致性 | 被权重违反 | 保持 |
| 可证伪性 | 弱 | 强 |
| Clamp 伪影 | 存在 | 无 |

**结论。** 贝叶斯模型在精度意义上并不比启发式"更好"——两者都给出点估计。贝叶斯模型**更诚实**：它发布不确定性而非将其隐藏在参数中，并且在数学上而非宣言上与对称性假设一致。
