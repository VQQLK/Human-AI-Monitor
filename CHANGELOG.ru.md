# Журнал изменений

Все значимые изменения в Human-AI Monitor будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Неопубликовано]

### Исправлено
- **Критическое наблюдение F6** из независимого Технического и Источникового Отчета о проверке (2026-09-20): Индекс разрыва теперь вычисляется на основе собранных сигналов, а не копирования начальных значений
  - Создан `src/services/gap-computation.ts` (75 строк) с функцией `computeGapIndex()`
  - Изменена `generateAndSaveProtocol()` для вызова `computeGapIndex()` вместо копирования последней строки
  - Результаты сохранены в таблицы `gap_history` и `index_history`
  - Проверено: разные недели с разным количеством элементов теперь дают разные оценки
  - Развертывание в production: Версия ID 9b676bd3, затем dc501a70, затем e3de304

- **Именование недель протокола** (Finding #1 из инженерного ревью)
  - `getWeekRange()` теперь возвращает понедельник как `start` (идентификатор протокола)
  - Протокол "2026-09-22" = неделя 22–28 сентября (понедельник–воскресенье)
  - Добавлены поля `filterStart` и `filterEnd` для SQL WHERE-запросов
  - `/gap` и markdown-генерация теперь сортируются по `recorded_at DESC` (сопутствующий фикс)

### Изменено
- Миграция базы данных 0003: Обновлен уровень SMD с 0.30 до 0.45
  - Причина: Anthropic достиг AL4 (26% задач, управляемых ИИ, >90% сотрудничества AL3)
  - Первый систем с устойчивым L4; порог остается "≥2 системы"
  - Обновлены как удаленная база данных, так и начальные данные в migrations/0001_initial_schema.sql
  - Ссылка: Индекс автоматизации исследований Anthropic (сентябрь 2026)

- Удален вспомогательный `wrangler.toml` (содержал только раздел `[site]`, не использовался)
- Обновлена версия `CITATION.cff` с 0.6.0 до 0.9.9
- Обновлена дата выпуска `CITATION.cff` с 2026-09-18 до 2026-09-21

### Добавлено
- Объявление о силе ИИ Трампа (19.09.2026) в раздел "Голоса" в README.md и README.ru.md

### Планируется
- Реальное покрытие тестами (парсер, классификатор, протокол)
- Рефакторинг: разделение монолитного src/index.ts на модули
- Парсинг HTML для нерсс-источников
- Декодирование HTML-сущностей для HTML-парсинга (например, `&#39;` → `'`)
- Android APK (PWA + Capacitor)
- Веб-интерфейс (Cloudflare Pages)
- Многопользовательская поддержка (EN / RU / ZH)

- Расписание Cron: `0 6 * * 1` (партия 1) + `30 6 * * 1` (партия 2)
