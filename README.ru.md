## Что это

`human-ai-monitor` — еженедельный протокол, отслеживающий **12 осей 
развития**:

**6 осей ИИ (RSI — Recursive Self-Improvement):**
- **SMD** — Глубина самомодификации
- **ITQ** — Траектория улучшения
- **AGG** — Автономная генерация целей
- **Cycle Velocity** — Скорость цикла улучшений
- **Verification** — Иерархия верификации
- **Hexad** — Детекция фазового перехода

**6 осей Человечества (HHI — Human Horizon Index):**
- **H1 Agency** — Агентность человека
- **H2 Sovereignty** — Когнитивный суверенитет
- **H3 Wellbeing** — Благополучие
- **H4 Equity** — Равенство и доступ
- **H5 Meaning** — Смысл и цель
- **H6 Democracy** — Устойчивость институтов

**Gap Index** — разрыв между развитием ИИ и состоянием Человечества.

---

## Зачем

Технологические лидеры провозглашают сингулярность. Ответственные за 
alignment признают отсутствие плана. Регуляторы предлагают добровольные 
меры. Учёные предупреждают о рассогласовании целей.

**Но никто не публикует еженедельный отчёт о том, что происходит с нами.**

Инструмент делает три вещи:
1. **Собирает** открытые данные из RSS, arXiv, новостных источников.
2. **Классифицирует** их по 12 осям с помощью LLM.
3. **Публикует** еженедельный протокол и Gap Index — бесплатно, открыто, 
воспроизводимо.

---

## Философия

- **Прозрачность**: все промпты и источники видны в репозитории.
- **Воспроизводимость**: каждый протокол ссылается на хеши данных.
- **Расширяемость**: добавить источник — одна строка в YAML.
- **Доступность**: Android-приложение + API для исследователей.
- **Независимость**: локальная LLM (Ollama + Qwen).
- **Бесплатность навсегда**: MIT License.

## Быстрый старт

```bash
git clone https://github.com/VQQLK/Human-AI-Monitor.git
cd Human-AI-Monitor
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m src.main --dry-run
```
