## Что это

`human-ai-monitor` — это еженедельный протокол, который отслеживает **12 
симметричных осей** плюс **геополитику** как мета-слой:

**6 симметричных осей ИИ (RSI — Рекурсивное самосовершенствование)** плюс 
**геополитика** (мета-слой):
- **SMD** — Глубина самомодификации
- **ITQ** — Качество траектории улучшения
- **AGG** — Автономная генерация целей
- **Cycle Velocity** — Скорость циклов улучшения
- **Verification** — Иерархия верификации
- **Hexad** — Детекция фазового перехода
- **Geopolitics** — Блоки управления ИИ (мета-слой)

**6 осей Человечества (HHI — Индекс человеческого горизонта):**
- **H1 Agency** — Агентность человека
- **H2 Sovereignty** — Когнитивный суверенитет
- **H3 Wellbeing** — Психическое здоровье и благополучие
- **H4 Equity** — Равенство и доступ
- **H5 Meaning** — Смысл и цель
- **H6 Democracy** — Институциональная устойчивость

**Индекс разрыва (Gap Index)** — разрыв между развитием ИИ и состоянием 
Человечества.

## Зачем

Технологические лидеры провозглашают сингулярность. Исследователи 
выравнивания признают отсутствие плана. Регуляторы предлагают добровольные 
меры. Учёные предупреждают о несовпадении целей.

**Но никто не публикует еженедельный отчёт о том, что происходит с нами.**

Этот инструмент делает три вещи:
1. **Собирает** открытые данные из RSS, arXiv, новостных источников.
2. **Классифицирует** их по 12 осям с помощью LLM.
3. **Публикует** еженедельный протокол и Индекс разрыва — бесплатно, 
открыто, воспроизводимо.

---

## Архитектура

- **Cloudflare Workers** (TypeScript) — среда выполнения, 10 API 
endpoints, Cron Trigger
- **Cloudflare D1** (Serverless SQLite) — 4 таблицы: items, protocols, 
gap_history, index_history
- **Cloudflare Workers AI** — модель классификатора: 
`@cf/qwen/qwen3-30b-a3b-fp8` (открытые весаы)
- **Cron Trigger** — расписание `0 6 * * 1` (каждый понедельник в 06:00 
UTC)

**Без внешних провайдеров ИИ.** Вся классификация выполняется на моделях с 
открытыми весами, размещённых в Cloudflare Workers AI.

## Философия

- **Прозрачность**: все промпты и источники видны в репозитории.
- **Воспроизводимость**: каждый протокол ссылается на хеши данных.
- **Расширяемость**: добавить источник = одна строка в массиве SOURCES.
- **Доступность**: публичный API + планируемое Android-приложение.
- **Независимость**: Cloudflare Workers AI с моделями с открытыми весами.
- **Бесплатно навсегда**: MIT License.

**MVP запущен:**

- ✅ База данных D1 (4 таблицы, заполнена)
- ✅ Классификатор Workers AI (Qwen 3, калиброван для 12 симметричных осей

- ✅ Сборщик RSS (12+ из 14 источников работают)
- ✅ Автогенерация еженедельных протоколов (Markdown)
- ✅ Cron Trigger (каждый понедельник в 06:00 UTC)
- ✅ Публичный API доступен по всему миру

**В процессе:**
- 🔄 Рефакторинг: разделение монолитного `src/index.ts` на модули
- 🔄 Реальное покрытие тестами (парсер, классификатор, протокол)
- 🔄 Android APK (PWA + Capacitor)
- 🔄 Веб-интерфейс (Cloudflare Pages)

**Дорожная карта:**
- [ ] Многоязычная поддержка (EN / RU / ZH)
- [ ] Push-уведомления о сдвигах порогов
- [ ] Парсинг HTML для источников без RSS
- [ ] Интеграция с глобальными индексами (V-Dem, WHR, Pew)
- [ ] Децентрализованное зеркало (IPFS)
- [ ] Независимый аудит методологии

**Известные ограничения:**
- ⚠️ Тесты — это boilerplate (шаблон Vitest); реальное покрытие в процессе
- ⚠️ Монолитный `src/index.ts` (~420 строк) — рефакторинг запланирован
- ⚠️ Сбор только через RSS; парсинг HTML ещё не реализован
- ⚠️ Поле `shift` может срабатывать слишком часто на общих новостях
- ⚠️ Конфигурации YAML (axes_ai.yaml, axes_human.yaml, sources_*.yaml) 
существуют, но ещё НЕ читаются Worker'ом; оси и источники захардкожены в 
`src/index.ts`
- ⚠️ Методологическая асимметрия: код реализует 13 осей (7 ИИ + 6 
Человеческих). 12 симметричных осей — это ядро; `геополитика` — это 
мета-слой, задокументированный отдельно в `docs/methodology.md`.
